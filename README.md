# PTPN11 phenotype class calculator

Offline-capable research implementation of the frozen six-indicator, three-class latent class model.

- `index.html`: English calculator
- `zh.html`: Chinese calculator
- Model and page version: 2026-11-03

All phenotype calculations run in the visitor’s browser. No patient-level research data are included. The pages do not upload or store the entered findings.

The tool reports class membership probabilities and profile interpretations. It does not provide a diagnosis, estimate prognosis, or determine treatment.

## GitHub Pages

In repository Settings > Pages, select Deploy from a branch, then main and /(root). Save.

This publication bundle intentionally excludes source patient records, case-level audits, workbooks, screenshots, and test fixtures.
