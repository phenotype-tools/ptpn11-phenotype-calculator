About the model and its scope

This tool estimates phenotype class membership using a fixed three-class model developed in 437 patients with PTPN11-related Noonan syndrome. The six indicators were selected from 20 candidate phenotypes and capture part of the multisystem spectrum of Noonan syndrome.

  • Class probabilities are calculated from the available indicators using the original model estimates. Documented absences contribute to the calculation, and unknown indicators are omitted.
  • A maximum posterior probability below 0.70 flags lower certainty in the class assignment.
  • The calculator reproduced the original model’s class assignments for all 437 development cases and 86 external cases.
  • The assigned profile can help focus bedside assessment and follow-up alongside standard multisystem evaluation and clinical judgment.
